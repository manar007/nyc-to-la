# NYC → LA

A seven-day coast-to-coast road trip companion: New York City to Los Angeles along I-70, I-44, and I-40.

The map, stop list, and day cards are interactive. Click a city for mileage, what to eat, and what to see.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:43187](http://localhost:43187).

## Stack

Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

No API keys. The itinerary is static.
